# ST (Suckless Terminal)

Personal build of ST

## Patches

- Anysize
- Boxdraw
- Column redraw
- Desktop entry
- Kitty Graphics Protocol
- Scrollback (and Mouse scrollback)
- Xresources with reload

## Keybinds

| Bind                 | Action          |
| -------------------- | --------------- |
| Ctrl + j             | Scroll down     |
| Ctrl + k             | Scroll up       |
| Ctrl + Shift + J     | Font -          |
| Ctrl + Shift + K     | Font +          |
| Ctrl + Shift + Space | Font size reset |
